# OpenAsstAI 第一阶段 Backlog

优先级说明：

- P0：第一阶段必须完成。
- P1：强烈建议完成，影响内测质量。
- P2：可以延后，但需要预留接口。

## Epic 1: 项目基础

| 优先级 | 任务 | 验收标准 |
| --- | --- | --- |
| P0 | 初始化前后端项目结构 | 本地可启动 Web 和 API 服务 |
| P0 | 配置数据库迁移 | 可以创建核心数据表 |
| P0 | 配置环境变量和 secret 管理约定 | 本地、测试、生产配置分离 |
| P0 | 建立基础日志格式 | API、节点、实例操作有统一日志 |

## Epic 2: 账号和权限

| 优先级 | 任务 | 验收标准 |
| --- | --- | --- |
| P0 | 用户注册/登录 | 用户可以登录并进入控制台 |
| P0 | Session/JWT 权限校验 | 未登录用户不能访问实例控制台 |
| P0 | 用户角色 | 支持 user 和 admin |
| P1 | 操作审计 | 关键操作写入 AuditLog |

## Epic 3: Agent 市场

| 优先级 | 任务 | 验收标准 |
| --- | --- | --- |

## 6 周执行节奏

### Week 1: 基础和市场

- 初始化项目。
- 完成账号、模板、套餐、实例数据模型。
- 完成市场列表、详情、创建流程 UI。

### Week 2: 节点和沙箱

- 完成官方节点 Agent。
- 完成 Docker 沙箱创建、启动、停止、销毁。
- 打通实例生命周期。

### Week 3: Agent 模板

- 接入 Hermes/OpenClaw 或统一 Template Adapter。
- 完成 Agent 配置注入。
- 完成健康检查和日志采集。

### Week 4: Models / Channels / Skills

- 完成 Models 配置。
- 完成 Web Chat。
- 完成内置 Skills 安装和启用。

### Week 5: Web Terminal / Usage

- 完成浏览器终端。
- 完成终端权限校验。
- 完成运行时长和费用估算。

### Week 6: 内测打磨

- 完成管理后台。
- 修复实例稳定性问题。
- 补充审计、安全限制和错误处理。
- 准备内测演示链路。

## 第一阶段完成定义

满足以下条件即可宣布 Phase 1 完成：

- 用户可以完整创建并运行一个 Agent 实例。
- 用户可以配置模型、Web Chat 和内置技能。
- 用户可以通过 Web Terminal 管理实例沙箱。
- 管理员可以看到节点、实例、日志和用量。
- 所有 P0 任务完成，P1 任务完成 60% 以上。
